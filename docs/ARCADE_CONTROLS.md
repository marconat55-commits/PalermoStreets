# Arcade controls

The control scheme deliberately uses two action buttons.

- Arrow keys: move in eight directions.
- J: four-hit arcade combo; aerial attack while airborne; acquire a nearby enemy and strike while holding them.
- K: jump; throw the held enemy while in grab state.
- Double-tap a direction: run horizontally, vertically or diagonally.
- Run + J: running knockdown attack.
- J+K: advancing fire special with temporary invulnerability and multi-enemy knockback. It does not consume health.

Outside a grab, the J+K chord always has priority over the individual J and K actions. During a grab, K has priority and performs the throw. A grab no longer starts merely by walking into an enemy and releases automatically if no follow-up is entered.
