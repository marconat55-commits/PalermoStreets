# Arcade controls

The control scheme deliberately uses two action buttons.

- Arrow keys: move in eight directions.
- A: mixed close-range combo; aerial attack while airborne; grab strike while holding an enemy.
- B: jump.
- Double-tap a direction: run horizontally, vertically or diagonally.
- Run + A: running knockdown attack.
- A+B: 360-degree special with temporary invulnerability and radial knockback. It costs 5% of maximum health only if at least one enemy is hit, and cannot reduce health below 1.

The A+B chord always has priority over the individual A and B actions.
