# Art source

Questa cartella contiene reference approvate e sorgenti di produzione. Non viene caricata dal runtime PixiJS.

## Marco

- `characters/marco/MARCO_MASTER_APPROVED.png`: identità, abbigliamento, palette e proporzioni ufficiali approvate l'11 agosto 2026.
- Ogni nuova posa deve essere confrontata con questa Master prima di entrare in `public/assets/characters/marco_anim/`.
- I PNG runtime restano su canvas trasparente 640×420, con pivot dei piedi determinato dai metadata.

Le tavole di revisione non appartengono alla build: vengono consegnate separatamente per consentire l'approvazione o la bocciatura frame per frame.
