# Talebano walk v2 — minimum visual contract

The six current source PNGs cannot form a correct alternating walk: five retain substantially the same leading-leg relationship and one is a gathered passing pose. Reordering them cannot create the missing opposite stride.

The replacement cycle must provide six right-facing, 640x420 transparent frames on the existing feet baseline:

1. right-foot contact;
2. right-foot load/down;
3. passing pose;
4. left-foot contact;
5. left-foot load/down;
6. opposite passing/recovery pose compatible with frame 1.

Acceptance requirements:

- same face, beard, sunglasses, tattoos, vest, trousers and shoes as the canonical Talebano;
- stable head and belly mass across the cycle;
- visible counter-swing of shoulders and arms;
- alternating feet with no repeated leading leg;
- no dynamic runtime scale and no cropped feet;
- first/last transition compatible with the lateral combat facing;
- approve contact-right, passing and contact-left key poses before producing in-betweens.

Until those key poses exist, the runtime keeps the current walk rather than introducing synthetic or misleading frames.
